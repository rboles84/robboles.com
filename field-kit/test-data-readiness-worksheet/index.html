Test Data Readiness Worksheet

Use this before a smoke or E2E path depends on data nobody can explain. The goal is to name the source, owner, refresh, reset, mutation, cleanup, and staleness signals before the suite starts manufacturing noise.

Download fillable HTML Read the post this came from →

How to use it

This page is the quick read. The useful artifact is the fillable download: open it before a run, type into it with the people who own the data, then print or save the completed worksheet without the site navigation.

1Pick one critical path

Do not audit every data problem at once. Start with one smoke path or E2E journey that regularly burns triage time.

2Name the data source

Decide whether the path relies on shared seed data, environment-specific data, dynamically created data, or some risky mix of all three.

3Separate stable from mutable

Mark which records are safe to reuse, which are safe to mutate, which must be reset, and which should be created fresh.

4Assign refresh and cleanup

Name who owns refresh cadence, junk-data cleanup, stale-data detection, and the escalation path when data blocks release confidence.

Readiness buckets

Use these buckets to avoid calling every data failure "flaky automation."

Source mismatchEnvironments do not share the same data source or contract, so the same test means different things in different places.
Stale dataThe record exists, but it no longer reflects the business rule, product state, or test assumption the suite depends on.
Unsafe mutationA test changes shared data and leaves the next run in a different state.
Junk accumulationOld manual and automated runs leave enough noise that tests have to filter around the environment.
Ownership gapThe data problem is real, but nobody owns refresh, reset, cleanup, or escalation.

The gut-check line

If the smoke test fails, can the team tell whether the data is missing, stale, dirty, mutated, or genuinely exposing a product defect? If not, the data layer is not ready enough for the result to mean what people think it means.

Watch out

Do not turn this into a spreadsheet nobody opens. Use it to make one critical path reliable, then repeat the pattern.
