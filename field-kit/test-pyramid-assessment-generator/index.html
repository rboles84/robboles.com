Test Pyramid Assessment Generator

Assess the shape of your automated test portfolio, surface likely risks, and generate a practical Markdown or text report you can keep, edit, share, or use to plan next steps.

Open generator Download HTML Read the post this came from →

How to use it

Enter the current number of automated tests at each layer, answer the diagnostic questions, then generate the assessment. Use the result as a strategy-review artifact: what is the portfolio proving, where is it expensive, and which checks should move down the stack before the UI suite grows again?

The tool runs locally in your browser. Your answers are not uploaded, transmitted, or stored.

What you get

The generator classifies the portfolio shape, summarizes the layer mix, flags likely risks, and exports a Markdown or text report you can edit after the session. The report is meant for a test-strategy review, not as a scorecard to shame the team.

When to use it

Use it when a suite feels slow, flaky, expensive, or hard to trust and the team needs to see whether too much proof is being forced through the UI layer.
