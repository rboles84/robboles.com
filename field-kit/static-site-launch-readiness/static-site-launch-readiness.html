Static Site Launch-Readiness Check

Run this against the deployed URL, not the local preview. Static sites still have seams; the job is to make them visible before users do.

Launch context

A check is done when there is evidence, not when the page looked fine.

1. No surprise phone-home

2. Metadata points at the live site

3. The page matches its source

4. Anything that submits, submits

5. Client code degrades, does not die

6. Links resolve where it is really hosted
